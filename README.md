# RathodX BuildCalc

A zero-dependency, privacy-friendly static website with construction and painting calculators for India.

## Deployment
Upload `index.html` and `robots.txt` to a static hosting provider (GitHub Pages, Cloudflare Pages or Netlify) under an account you control. A deployment account is not yet connected; **site is not live**.

## Monetization
Do not claim revenue until a payment provider or ad network has accepted the site and actual transactions are verified. Useful content, traffic and compliance are required; a calculator alone does not produce income.

## Local test
Open `index.html` in a browser and verify area=1000, rate=1800, contingency=10 gives ₹19,80,000. Paint: 40×10−50=350 sq ft.
